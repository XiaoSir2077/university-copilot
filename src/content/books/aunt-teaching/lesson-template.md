# 教案通用模板（基础薄弱班专用）

> 适用：职高高中、学生英语基础薄弱的班级。等教材版本确认后，会按每个单元补充配套的完整教案实例。

## 一、动手备课前，先想清楚 3 件事

1. **下课铃响时，学生能做到什么？** 目标要能看见、能检查，比如"能用 3 句话描述某人的周末"，而不是"掌握一般过去时"。
2. **这节课学生最可能卡在哪？** 是生词太多、句子看不懂，还是不敢开口？卡点决定了你要搭多少"台阶"。
3. **这节课只解决几个问题？** 基础薄弱班一节课主攻 **1 个主目标**，贪多必然夹生。

## 二、教案标准骨架

| 板块 | 要写什么 |
|---|---|
| 课题 | 单元 + 课型，如 Unit 3 Reading（第 1 课时） |
| 课型 | 阅读 / 听说 / 语法 / 词汇 / 写作 / 试卷讲评 |
| 教学目标 | 知识目标、能力目标、情感目标（各 1-2 条，用"能说出/能填对/能读懂"开头） |
| 教学重点 | 这节课必须拿下的语言点 |
| 教学难点 | 学生最容易错、最容易混的地方 |
| 学情分析 | 全班基础、已会什么、怕什么 |
| 教学方法 | 任务型教学 / 讲练结合 / 小组合作（写实际用得上的） |
| 教学过程 | 见第三节，按环节写清"教师做什么、学生做什么、为什么这么设计" |
| 板书设计 | 课前规划好主板书区，课上不临时乱写 |
| 作业 | 分层：A 层人人必做，B 层鼓励选做 |
| 教学反思 | 课后花 3 分钟补：哪个环节学生卡住了，下次怎么改 |

## 三、阅读课教学过程模板（高中最常用）

阅读课按 **PWP** 三段走：Pre-reading → While-reading → Post-reading。

| 环节 | 时长 | 教师活动 | 学生活动 | 设计意图 |
|---|---|---|---|---|
| 导入 Pre-reading | 5-8 分钟 | 用图片/短视频/一个生活问题引入；板书 3-5 个"拦路词"（不超过 8 个），带读两遍；让学生看标题和插图猜内容 | 回答简单问题、跟读单词、大胆预测 | 激活背景、扫清最致命的生词障碍、带着目的读 |
| 快速阅读 Fast reading | 4-5 分钟 | 布置 **1 个**简单任务：主旨连线、段落排序、判断文章大意；要求限时、允许猜 | 限时默读，完成简单任务 | 训练抓大意，基础差的学生也能做对，建立信心 |
| 仔细阅读 Careful reading | 12-15 分钟 | 分 2-3 轮下发任务，难度爬坡：判断正误 → 单项选择 → 填表格；每轮先核对再进下一轮 | 再读课文，逐段找答案，同桌互对 | 小步子+多次回文，保证中下游跟得上 |
| 读后产出 Post-reading | 8-10 分钟 | 给"复述支架"（关键词/表格/句型框架，如 `I think … because …`）；组织 2 人小组说，再请 1-2 组展示 | 借助支架复述或谈看法 | 把输入变成输出；有框架才敢开口 |
| 小结 Summary | 2-3 分钟 | 请学生总结"今天学了什么"，教师补漏 | 学生口头总结 | 当堂巩固，也检验目标达成 |

> 听说课把"读"换成"听"，同样是听前铺垫 → 听中分层任务（泛听 1 题 + 精听 2-3 题）→ 听后说；语法课用"例句观察 → 学生找规律 → 归纳规则 → 少量精练"，不要一上来讲规则。

## 四、基础薄弱班的 6 条实操原则

1. **小步子**：一个活动只练一个点，一个指令只说一件事。
2. **多复现**：核心词争取在一节课里以"读到→听到→说到→写到"出现 5 次以上。
3. **降坡度**：填空给首字母、选择给 4 个选项、表达给例句和句型框架——**给台阶不等于降低目标**。
4. **双语指令**：关键指令中英各说一遍，新活动一定先做一个示范（teacher models first）。
5. **分层不批判**：A 任务保底人人做，B 任务鼓励做；做不对不批评，先让他听到正确版本。
6. **即时正反馈**：学生答错，教师先平静复述正确答案（"OK, listen: …"），再让他跟一遍，保护开口意愿。

## 五、分层作业设计

| 层级 | 内容 | 要求 |
|---|---|---|
| A 层（必做，保底） | 单词跟读 + 抄写核心词/句 + 5 道基础题 | 当天交，全批或抽批 |
| B 层（选做，提高） | 仿写 2-3 个句子、编 1 组小对话、复述课文 | 自愿，做了就在课上点名表扬 |
